# ПО для P3-34

## Что делает
Данная программа позволяет удобно взаимодействовать с устройством P3-34.
Она предлагает задать ряд параметров измерения и заполнить данные об
образце, после чего позволяет запустить цикл измерений. В процессе работы она создаёт
csv файл и сразу же записывает туда полученные данные. После окончания измерений
предлагает собрать готовый xlsx файл с данными (аналогично GHzPrint).

## Как использовать
Для работы необходимо соединение по Bluetooth с P3-34. После запуска программы
необходимо убедиться, что все поля заполнены актуальными данными, после чего можно
нажимать "Начать измерение" для запуска цикла по заданным параметрам.
При необходимости можно прервать цикл повторным нажатием. При старте цикла создаётся
csv файл с именем образца, в котором заполняется шапка с данными с P3-34, после чего
начинается первое измерение. В конце каждого измерения полученные данные сразу же
сохраняются в csv файл, так что при прерывании уже записанные данные сохранятся.

После запуска поля уже заполнены стандартными данными, эти поля обязательно должны быть
заполнены:
* Количество циклов 30
* Длительность цикла (мин) 2
* Частота 2,2
* Сохранять в *путь до рабочего стола*\p3-34\P3-34 measurements<br>
При запуске автоматически указывается папка на рабочем столе p3-34 с папкой
P3-34 measurements, куда сохраняются промежуточные результаты - csv на отдельный
образец после каждого измерения и xlsx файл с суммарными результатами за этот день
измерений.

Необязательные, но желательные данные:
* Имя текущего образца "И"<br>
  Не обязательно иметь "И" в имени образца, но само имя должно отличаться от других,
  оно будет вписано в имя создаваемого csv файла, а также в сам файл.
* Номер заказа<br>
  Он будет записан внутрь csv файла, и в дальнейшем также потребуется при создании
  xlsx файла при объединении результатов за день измерений.

Кнопки:
* Начать измерение (заменяется на "Остановить" при запуске)<br>
Начинает цикл измерений. После окончания полного цикла измерений он сам остановится,
если прервать до завершения последнего измерения, то данные от него не сохранятся.
* Собрать .xlsx за сегодня<br>
Собирает все файлы с измерениями за сегодня в готовую для обработки xlsx таблицу, со
страницами сырых данных.

Ниже информационное поле со статусом текущего цикла измерений, выводом ошибок и прочей
информации. Рядом с ним для каждого отдельного измерения показывается прогресс бар,
чтобы было понятно сколько времени осталось до окончания конкретного измерения.

## Как работает
Сразу после запуска для проверки соединения пингуем P3-34, если не получаем ответ, то
выводим в статус, что произошла ошибка соединения, и через 5 секунд повторим проверку.
