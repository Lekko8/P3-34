# ПО для P3-34

## Что делает

Данная программа позволяет удобно взаимодействовать с устройством P3-34.
Она предлагает задать ряд параметров измерения и заполнить данные об
образце, после чего позволяет запустить цикл измерений. В процессе работы она создаёт
csv файлы для каждого образца и сразу же записывает туда полученные данные.
После окончания измерений предлагает собрать готовый xlsx файл с данными
(аналогично GHzPrint).

## Как использовать

Для работы необходимо соединение по Bluetooth с P3-34. После запуска программы
необходимо убедиться, что все поля заполнены актуальными данными, после чего можно
нажимать "Начать измерение" для запуска цикла по заданным параметрам.
При необходимости можно прервать цикл повторным нажатием. На старте цикла создаётся
csv файл с номером образца в имени файла, в который записывается шапка с данными с
P3-34, после чего начинается первое измерение. В конце каждого измерения полученные
данные сразу же сохраняются в csv файл, так что при прерывании цикла ранее записанные
данные сохранятся.

После запуска поля уже заполнены стандартными данными, эти поля обязательно должны быть
заполнены:
* Количество циклов 30
* Длительность 2
* Частота 2,2
* Пороговое 0,5
* Сохранять в *путь до рабочего стола*\p3-34\P3-34 measurements


При запуске автоматически указывается папка p3-34 с папкой P3-34 measurements,
в которой создаётся папка под сегодняшнюю дату, куда сохраняются промежуточные
результаты - csv на отдельный образец после каждого измерения и xlsx файл с
суммарными результатами за этот день измерений. После самого первого запуска создаётся
файл settings.txt, куда сохраняется порт подключения, а также все параметры выше,
кроме пути к папке сохранения (в ней генерируются подпапки в зависимости от даты).

Необязательные, но желательные данные:
* Имя текущего образца "И"  
  Не обязательно иметь "И" в имени образца, но само имя должно отличаться от других,
  оно будет вписано в имя создаваемого csv файла, а также в финальный xlsx файл.
* Номер заказа  
  Он будет записан внутрь csv файла, и в дальнейшем также потребуется при создании
  xlsx файла при объединении результатов за день измерений.

Кнопки:
* Начать измерение (заменяется на "Остановить" после нажатия)  
Начинает цикл измерений. После окончания полного цикла измерений он сам остановится,
если прервать до завершения последнего измерения, то данные от него не сохранятся.
* Собрать .xlsx за сегодня  
Собирает все файлы с измерениями за сегодня в готовую для обработки xlsx таблицу, со
страницами сырых данных.

Ниже - информационное поле со статусом текущего цикла измерений, выводом ошибок и прочей
информации. Рядом с ним для каждого отдельного измерения показывается прогресс бар,
чтобы было понятно сколько времени осталось до окончания конкретного измерения.

## Как работает

Краткое содержание только значимых для логики функций по соответствующим файлам:

### GUI.go

Кнопка "Начать измерение":
1. если runner nil, то кладём в него **NewMeasRun**
2. если runner.isWorking - **stop** и return
3. если runner.**testPingBt** - **run**

### funcs.go

Функция **NewMeasRun**: возвращает &MeasRun{...} - структуру со всей информацией для
взаимодействия всех элементов между собой, все функции в этом файле используют её

Функция **stop**:
1. ставит isWorking false
2. ставит на кнопку "Начать измерение"
3. ставит на статус "Измерение прервано"
4. обнуляет прогресс бар

Функция **run**: принимает параметры циклов измерения
1. если isWorking, то return
2. читает totalCycles и cycleMinutes 
3. обнуляет currentCycle и progress 
4. ставит isWorking true
5. через Synchronize ставит на кнопку "Остановить"
6. запускает горутину runLoop

Функция **runLoop**: принимает частоту freq
1. в конце всегда ставит на кнопку "Начать измерение", isWorking false и обнуляет currentCycle
2. **getInfo** и **newCSV**
3. в цикле по количеству циклов измерений:
   1. если отмена, то ставим статус прервано на цикле, обнуляем прогресс бар и return
   2. обновляем цикл через **updateCycle**
   3. запускаем **doMeas**, в случае ошибки прерываем как в (i)
4. ставим **updateStatus** "Измерение завершено" и прогресс бар на 100

Функция **doMeas**:
1. запускает горутину **meas** и читает результат
2. если не отменили, то пишет результаты и обнуляет прогресс бар
3. повторяет текущий цикл, если не пришло подтверждение, что результат соответствует критериям

Функция **meas**:
1. пока не кончится время обновляет прогресс бар
2. по окончании времени ставит прогресс бар 100 и возвращает **getMeas**
3. если прогресс бар%10 = 0, то ставит в статус текущий цикл

### measurements.go

Функция **getMeas** возвращает *MEAS:AVR*, *MEAS:MAX* и говорит начать *NEWMEAS*

Функция **getInfo** возвращает *?*, *UBATT*, *FREQ* (если freq не пустой)
и говорит начать *NEWMEAS*

Функция **getTestPing**:
1. отправляет *TEST*
2. в случае ошибки отправки, чтения или любой другой возвращает сообщение ошибки и false
3. если всё корректно, то возвращает ответ прибора и true

### Подробное описание работы с bt портом в main.go:

```Go
type Data struct {
    Order     string // номер заказа
    Port      string // номер порта (COM<цифра>)
    Interval  string // промежуток между измерениями
    Frequency string // частота
    ID        string // 26
    Name      string // P3_34_UHF
    Number    string // 54826
    Soft      string // V2.0
    Battery   string // заряд батареи
}
```

1. Инициализация структур, причём настройки сразу заполняются дефолтными данными

```Go
var (
	d = &Data{}
	s = &Settings{
        totalCycles:  30,
        cycleMinutes: 2,
        freq:         "2,2",
        borderNum:    "0,5",
    }
)

```

2. Пробуем открыть порт:
```Go
err := openPort(d)
```

Эта функция сначала пытается открыть сохранённый порт, затем,
если сохранённый порт доступен, то проверяет через него соединение с устройством.
Если проверка проходит успешно, то передаём открытый порт в управление всей программе,
а также запоминаем сохранённый порт записью в ```d.Port```. В случае ошибки на любом
этапе возвращаем ```scanPorts()```, что просканирует все порты анализируя их на
возможность соединения с устройством.

3. Затем, если получаем ошибку, то через проверку в ```if``` показываем ```errGUI```,
который возвращает ```true``` при нажатии ```Должно работать```. Тогда, инициируем запуск
основного окна через ```initGUI()```.

Эта функция сначала запускает загрузку настроек из файла:
```Go
err = s.LoadSettings(d)
```

Она читает ```settingsFileName``` и заполняет ```s *Settings```:
* d.Port
* s.totalCycles
* s.cycleMinutes
* s.freq
* s.borderNum

В случае любой ошибки возвращает ```"COM"```. 

После успешной загрузки настроек и подключения к устройству запускаем основное окно.

4. Если ошибок в ```openPort()``` не было, то сразу запускаем ```initGUI()```.

5. В конце срабатывает defer на сохранение настроек через
```Go
s.SaveSettings(d)
```

В ней создаётся файл ```settingsFileName``` и заполняется
* d.Port
* s.totalCycles
* s.cycleMinutes
* s.freq
* s.borderNum

А также через defer закрывается порт, с которым работаем.
